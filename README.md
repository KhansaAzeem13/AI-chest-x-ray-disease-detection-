# 🫁 AI Chest X-Ray Diagnostic System

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Click_Here-red?style=for-the-badge)](https://cdnqb7bcufherdd9bfyfsp.streamlit.app/)

An AI-powered system that detects **14 thoracic diseases** from chest X-rays using **DenseNet121 Transfer Learning** with **Grad-CAM explainability**.

## 🌐 Live Demo
👉 **[https://cdnqb7bcufherdd9bfyfsp.streamlit.app/](https://cdnqb7bcufherdd9bfyfsp.streamlit.app/)**

## ✨ Features
- 🤖 Detects 14 chest diseases using DenseNet121
- 🔥 Grad-CAM heatmaps for visual explainability
- 🏥 Hospital-style professional report generation
- 🖨️ Print/Download report as PDF

## 🛠️ Tools Used
`Python` `TensorFlow` `tf-keras` `DenseNet121` `Grad-CAM` `Streamlit` `OpenCV` `Google Colab GPU` `NIH ChestX-ray14`

## 📄 CV Description
> Built an AI chest X-ray diagnostic system using DenseNet121 Transfer Learning to detect 14 thoracic diseases. Implemented Grad-CAM explainability heatmaps and a hospital-style report generator. Deployed as a live Streamlit web app.
